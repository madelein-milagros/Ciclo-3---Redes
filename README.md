## 🛠️ Cómo desplegar este proyecto

### 1. GitHub
1. Crea un repo en GitHub: `roadmap-redes-milagros`.
2. Sube todos los archivos.

### 2. Vercel
1. Conecta tu GitHub a [Vercel](https://vercel.com).
2. Importa el proyecto.
3. ¡Listo! Vercel te dará un link público profesional.
